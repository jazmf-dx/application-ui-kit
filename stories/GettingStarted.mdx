# UI Platform Catalog

この Storybook は、**UI Platform の Catalog 兼 開発・テスト環境**です。
Components / Patterns / Templates をアプリ本体から切り離して確認・比較・検証するために使います。
Story を増やすこと自体ではなく、UI を探す・比較する・理解する・検証するコストを下げることが目的です。

## Catalog の見方

目的に応じて入口を選びます。

```
ギャラリー           使える部品を俯瞰する
Component Overview   1つの部品の種類・状態を比較する
Individual Story     実際の挙動を確認する
パターン             UX上の問題に対する候補を比較する
テンプレート         画面レベルの構成例を見る
```

Component を利用するときは、ギャラリー → Overview → Individual Story の順に見ると、探す → 比べる → 確かめるの粒度で確認できます。

実装時は、必要に応じて Pattern / Template も先に確認してください。UI設計の候補を比較したい場合は Pattern、画面全体の構成を参考にしたい場合は Template を使います。

`application-ui-kit` を採用しているアプリでは、利用する Component を実際の依存versionで確認してから import します。
実パッケージの scope は publish 元で変わりますが、利用側 `package.json` の npm alias によりコード上の名前は固定します。

```tsx
import { Button } from 'application-ui-kit'
import 'application-ui-kit/styles.css'

<Button variant="primary">保存</Button>
```

## 構成

```
はじめに
  概要                 このページ
  Django Islands       Django へ React を埋め込む

基礎                   色・文字・余白などのトークン
  色
  文字
  余白
  角丸と影
  アイコン

コンポーネント          部品 1 つずつ
  Button
    Overview           variant / size / 状態の比較
    Primary            個別 Story
    Secondary
    ...
  Input
  ...

パターン               UX上の問題ごとに解決候補を比較
  単一選択
  ...

テンプレート           複数のPattern / Componentを組み合わせた画面構成例
  ...

ギャラリー             全体の俯瞰
  全コンポーネント
```

サイドバーの見出しは日本語にしています。**コンポーネント名は import 名なので訳しません**
（`Button` はそのまま）。

基礎は**実装時に確認が必要な情報だけ**を置きます。
Storybook を独立した巨大なデザインシステムにはしません。

Pattern は Component 名ではなく設計上の問題を単位にし、複数の有力な解決候補と選択条件を比較します。一般的な UI Pattern を網羅するためだけには増やしません。

Template は複数の Pattern / Component を組み合わせた画面レベルの構成例です。アプリ固有の API・権限・業務ルールは持ち込みません。

## Story を追加するとき

**すべての状態を機械的に Story 化しません。** Story の数を増やすことが目的ではなく、
UI を探す・比較する・理解する・検証するコストを下げることが目的です。

Component Story は次のいずれかに当てはまるものを優先します。

- 複数のバリエーションがある
- 状態によって見た目が大きく変わる
- Loading / Error / Empty を持つ
- UI レビューで確認する価値がある
- 実アプリでは再現しにくい（通信エラー、長い文字列、境界値など）
- Visual Regression Test の対象にしたい
- 使い方を間違えやすい

Pattern / Template は実案件で同じ設計判断や画面構成に再び迷う可能性があるときに追加します。網羅性のためだけには追加しません。

## 開発

```
bun install
bun run storybook          # http://localhost:6006
bun run build-storybook    # 静的ビルド（CI で通ることを確認している）
```

コンポーネントや Story を変更したら、次を確認してください。

```
bun run typecheck
bun run test
bun run lint
bun run build-storybook
```

品質確認の観点（a11y、キーボード操作、狭い画面、reduced motion など）は
リポジトリ直下の `README.md` を参照してください。
