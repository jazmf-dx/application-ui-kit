### カードの角丸と余白は導出する

カードだけは固定値ではなく、**中の一番大きい文字**から角丸と内側余白を導出します。
どちらも同じ値なので、余白と角の曲がりが常に釣り合います。

```
padding = border-radius = 見出しの文字サイズ ÷ √φ   （√φ = 1.272）
```

<SpecTable
  head={['クラス', '見出しのサイズ', '余白 = 角丸']}
  rows={[
    [<Code>{'<Card size="sm">'}</Code>, '14px（text-sm）', '11.01px'],
    [<Code>{'<Card>'}</Code>, '16px（text-base）', '12.58px'],
    [<Code>card-lg</Code>, '24px（text-2xl）', '18.87px'],
  ]}
/>

見出しが大きいカードほど余白が広がります。固定の `p-3` / `p-4` / `p-6` だと
中身に関係なく同じ余白になり、大きい見出しのカードだけ窮屈に見えます。
出典は LiftKit（`registry/nextjs/components/card/card.css`）の
`--opticCorrectedPadding` です。

CSS は子要素の文字サイズを読めないため、`Card` の `size` プロップで明示的に
渡しています。`className="p-6"` のような上書きはしないでください
（余白だけが動いて角丸と釣り合わなくなります）。

## シャドウ

**`shadow-sm` のみを使います。** 影で階層を表現しようとすると、
画面ごとに深さがばらつき、結果として立体感ではなく散らかった印象になります。
階層はボーダーと背景色（`bg-card` / `bg-muted`）で表現してください。

<SpecTable
  head={['クラス', '見本', '用途', '可否']}
  rows={SHADOW_SCALE.map((s) => [
    <Code>{s.cls}</Code>,
    <div className={`h-12 w-20 rounded-xl border border-border bg-card ${s.cls}`} />,
    s.usage,
    s.allowed ? '✓ 使う' : '✗ 使わない',
  ])}
/>

`shadow-lg` は**ドロップダウン・ポップオーバーなど、他の要素の上に浮く要素だけ**の例外です。
浮遊要素は影がないと背後のコンテンツと混ざって読めなくなります。

<DoDont
  doText={<>カードは <Code>card</Code>（<Code>shadow-sm</Code> 込み）を使う</>}
  dontText={<><Code>shadow-md</Code> / <Code>shadow-xl</Code> / <Code>shadow-2xl</Code> でカードを目立たせる</>}
/>

**カードを入れ子にしない**でください（`ai-dev-standards/components.md`）。
影付きのカードの中に影付きのカードを置くと境界が判別できなくなります。
入れ子が必要に見えるときは、内側を `border` だけの区画にします。

## トランジション

<SpecTable
  head={['クラス', '用途']}
  rows={TRANSITIONS.map((t) => [<Code>{t.cls}</Code>, t.usage])}
/>

- ホバー・フォーカスの変化は `transition-colors` を使います
- `transition-all` は使いません。意図しないプロパティ（レイアウト）まで
  アニメーションして、描画が重くなります
- ダイアログ・ドロップダウンの出入りは `tw-animate-css` の
  `animate-in` / `fade-in-0` / `zoom-in-95` / `slide-in-from-*` を使います
  （`Dialog` / `Dropdown` に実装済み）

## モーション配慮

{REDUCED_MOTION_NOTE}

OS で「視差効果を減らす」を設定しているユーザーがいます。
めまいや吐き気を引き起こすことがあるため、**装飾的なアニメーションは無効化できるようにします**。

```css
@media (prefers-reduced-motion: reduce) {
  .animate-pulse { animation: none; }
}
```

状態変化を伝える短いトランジション（`transition-colors`）はそのままで構いません。
問題になるのは、大きく動く・繰り返す・自動で始まるアニメーションです。

出典: `ai-dev-standards/accessibility.md`
