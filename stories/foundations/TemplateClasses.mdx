# テンプレート用クラス

Django テンプレートから「素の HTML + class」で使う部品の見本です。
定義は `tokens/classes.css`（`application-ui-kit/styles.css` に含まれる）。
ここに並ぶクラス名がパッケージの **公開契約** で、追加は MINOR、rename / 削除は MAJOR
（`decisions/adr-0007`）。

React コンポーネントの中ではこれらのクラスを書かず、対応するコンポーネントを使います。
見た目は 1:1 に揃えてあるので、テンプレートで描いた画面と React で描いた画面が並んでも差が出ません。

<SpecTable
  head={['テンプレート用クラス', 'React', '用途']}
  rows={[
    [<Code>btn-primary / btn-secondary / btn-success / btn-danger</Code>, <Code>Button</Code>, '操作。サイズは btn-xs / btn-sm / btn-lg'],
    [<Code>input-field</Code>, <Code>Input / Select / Textarea</Code>, 'フォーム入力'],
    [<Code>card / card-sm / card-lg</Code>, <Code>Card</Code>, '面'],
    [<Code>badge badge-{'{tone}'}</Code>, <Code>Badge tone</Code>, '状態表示'],
    [<Code>alert alert-{'{tone}'}</Code>, <Code>Alert</Code>, '継続して伝える注意・案内'],
    [<Code>breadcrumbs</Code>, <Code>Breadcrumbs</Code>, '現在位置'],
    [<Code>page-header</Code>, <Code>PageHeader</Code>, '画面の見出し領域'],
    [<Code>stat</Code>, <Code>Stat</Code>, 'KPI・統計タイル'],
    [<Code>data-table</Code>, <Code>Table</Code>, '一覧'],
    [<Code>tabs / tab / tab-active</Code>, <><Code>Tabs</Code> / Islands <Code>tabs</Code></>, '画面内の切替'],
    [<Code>disclosure</Code>, <><Code>Accordion / Collapsible</Code> / Islands <Code>disclosure</Code></>, '開閉（details 要素）'],
    [<Code>avatar-sm / avatar-md / avatar-lg</Code>, '—', 'アバター（React 版は予定）'],
  ]}
/>

- 色は Token（`var(--color-*)`）だけで書かれているので、`<html class="dark">` でも
  `[data-theme="dark"]` で Token を差し替える方式でも、そのまま暗くなります
- 利用側が同名のクラスを自前で定義している場合は、`styles.css` を読み込んだうえで
  **自前の定義を削除**してください。残すと読み込み順で自前が勝ち、何も変わりません
- 末尾にアイコンを置くときは `<svg>` を `<span>` で包みます（`:first-child` の判定のため）
